# CampusBlog AI 软件需求规格摘要

## 问题定义

校园课程、项目实践与技术经验常散落在聊天记录和个人文件中。普通博客只能发布和阅读，缺少内容提炼、组织和针对性理解能力。

## 角色

- 游客：浏览、搜索、按标签筛选文章。
- 登录用户：发表文章、评论、使用文章问答。
- 作者：编辑和删除自己的文章、修订 AI 摘要和标签、使用写作助手。

## 核心用例

1. 用户注册或登录。
2. 作者撰写 Markdown 文章并发布。
3. 系统异步生成摘要和标签；失败时保留人工内容。
4. 作者通过写作助手生成大纲、续写、改写或标题建议，确认后插入。
5. 读者针对当前文章提问，系统仅依据文章回答。
6. 用户搜索文章、筛选标签和发表评论。

## 非功能需求

- AI 不可用不得阻止文章保存。
- 密钥不得进入仓库；密码使用 BCrypt。
- AI 每用户每日默认限制 50 次，单次超时默认 60 秒。
- 前后端构建、测试和 Compose 配置必须由 CI 验证。
- 页面适配桌面和移动设备，动态输出使用 `aria-live`。
