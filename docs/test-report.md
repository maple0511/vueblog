# 软件测试报告

## 测试策略

- 单元测试：认证状态、AI 元数据解析、权限规则。
- Web 集成测试：注册、登录、受保护接口、文章和评论生命周期。
- 前端测试：Pinia 状态、Markdown 清洗、流式解析。
- 部署测试：Compose 配置、容器健康检查、数据持久化和公网访问。

## 关键黑盒用例

| 编号 | 场景 | 预期 |
|---|---|---|
| B01 | 合法注册 | 201，返回 JWT 和用户信息 |
| B02 | 重复用户名/邮箱 | 409 |

| B04 | 未登录发布文章 | 401 |

| B08 | AI 问答超出文章内容 | 回答“该文章未提供相关信息” |
| B09 | 超过每日 AI 配额 | 429 |
| B10 | 恶意 Markdown | 前端清除危险 HTML |

## 白盒关注点

- `AuthService` 的唯一性、密码匹配和令牌生成分支。
- `PostService` 的作者所有权、标签替换和 AI 降级分支。
- `AiMetadataService` 的 JSON、摘要长度、标签数量和失败状态分支。
- `AiStreamService` 的完成、中止、异常和日志分支。
